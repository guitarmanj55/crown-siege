# Crown Siege

Fantasy single-lane strategy game in the style of Stick War: hold your keep, topple the Horde's dark tower. Plays as an offline iPhone home-screen app (landscape).

**Live:** https://guitarmanj55.github.io/crown-siege/

## Run it
```bash
npm test          # simulation, progress and scripted-player tests
```
Serve the folder with any static server on port 8131 and open it. No build step, no dependencies; all art is procedural Canvas 2D.
